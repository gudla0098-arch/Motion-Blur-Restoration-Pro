# Security Policy

## Supported versions

Security fixes are applied to the current version on the `main` branch.

## Reporting a vulnerability

Please do not disclose security vulnerabilities in public issues.

Instead, use GitHub's private vulnerability reporting feature for this repository, if available. Include:

- A clear description of the issue.
- Steps to reproduce the behavior.
- The potential impact.
- Any suggested mitigation.

Please allow time for investigation and a fix before publicly sharing vulnerability details.

## Responsible use

- Do not upload images containing sensitive or private information to a public deployment.
- Do not commit API keys, passwords, tokens, personal data or private images.
- Keep dependencies updated and review changes before deployment.
