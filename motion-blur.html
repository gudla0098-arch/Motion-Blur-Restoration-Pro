03 — UNDER THE HOOD

Restoration is a
modeled process.

Motion blur occurs when a camera or subject moves during exposure. This lab builds an approximate point-spread function (PSF) from the parameters you provide, then applies Wiener deconvolution to attempt recovery.

01 / MODEL

Describe the motion

Select a blur model and provide an estimated direction and length to define the PSF prior.

02 / DECONVOLVE

Recover image detail

Use a frequency-domain Wiener filter to reverse the modeled blur while limiting noise amplification.

03 / INSPECT

Evaluate the output

Compare the restored image with the input. Results are estimates, not guaranteed reconstructions.

IMPORTANT SCOPE NOTE

This project is model-based restoration, not blind estimation of an unknown blur kernel. Circular and non-uniform options are simplified approximations. Severe blur, noise, and inaccurate parameters can limit restoration quality.
